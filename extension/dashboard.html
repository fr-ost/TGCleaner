Start the local service

The extension talks only to a small service on your computer, which talks to Telegram.

  1. Open a terminal in the project folder.
  2. Run ./start.sh (macOS/Linux) or start.bat (Windows).
  3. Leave that window open while you use this page.

Connect your Telegram account

Your number, login code and password go only to the local service and on to Telegram. They are never stored or logged.
